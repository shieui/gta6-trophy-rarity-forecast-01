A program that forecasts, for every PS5 trophy of Grand Theft Auto VI, the percent of players Exophase tracks who will have earned it at 2026-11-26T00:00Z, as five quantiles per trophy, scored by pinball loss on the logit scale.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
